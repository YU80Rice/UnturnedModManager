# 03: 沙箱违规拦截红牌告警与安全预检

**What to build:** 在任何外部 `.ummpk` 或 `.ummtheme` 导入前，启动器执行不可绕过的多层沙箱预检。若发现危险可执行脚本（`.exe`、`.bat`、`.cmd`、`.ps1`、`.vbs` 等）、路径穿越攻击（`..` 目录逃逸）、解压条目超限（>4096）或解压体积超限（>1GB），立即强行终止导入流程，不提供“继续导入”按钮，弹出醒目的红色安全警示对话框，展示违规条目明细与拦截规则原因，并支持一键复制诊断信息，彻底阻断恶意文件危害。

**Blocked by:** 02: 启动传参与单实例安全队列分发

**Status:** ready-for-agent

- [ ] 实现针对 `.ummpk` 与 `.ummtheme` 的压缩包多层沙箱安全预检服务
- [ ] 严格拦截危险扩展名、路径穿越、Zip 炸弹与非法目标路径
- [ ] 弹出专用的红色警示对话框，列出被拦截的文件明细与违规规则，不提供导入操作
- [ ] 提供一键复制违规排障信息功能
- [ ] 包含针对恶意构造 Zip（含脚本、含穿越路径、含虚假扩展名）的沙箱自动化单元测试
