# 03: 设置页交互控制面板与实时双滑块联动端到端验证

Type: task
Status: ready-for-agent
Blocked by: 01, 02

## 问题

玩家在主界面中缺少配置与管理个人壁纸的直观入口，无法通过文件选择器选取图片、缺乏一键清除壁纸的能力，且无法实时拖动滑块直观调节背景高斯模糊度与遮罩浓度；同时需要对极端亮色与暗色壁纸场景进行全套 WCAG AA 4.5:1 无障碍对比度守卫与发布包打包验证。

如何实装“启动器壁纸与个性化”控制面板，并完成全链路端到端闭环验证？

## 验收条件

- [ ] 在 `SettingsPage.xaml` 新增“启动器背景壁纸与个性化”卡片组，包含当前壁纸状态指示、选择壁纸与清除壁纸按钮
- [ ] 在卡片组中集成双实时调节滑块：
  - “背景模糊程度”滑块：`0 ~ 40 px`，附带动态数值文本指示（如 `15 px (柔和)`）
  - “背景遮罩浓度”滑块：`10% ~ 80%`，附带动态百分比指示（如 `35%`）
- [ ] 交互联动：点击“选择壁纸”弹出系统文件对话框，选取有效图片后即刻刷新主窗口背景；拖动滑块时主窗口高斯模糊与遮罩即拖即见效并自动持久化；点击“清除壁纸”一键回退纯色
- [ ] 编写端到端状态机测试覆盖：设置壁纸 -> 动态调节模糊度 -> 动态调节遮罩 -> 切换深浅日夜模式 -> 清除壁纸全流程
- [ ] 编写对比度守卫自动化断言：在极端亮色与暗色壁纸场景下，卡片内核心文字与重要操作按钮依然 100% 守住 WCAG AA 4.5:1 对比度红线
- [ ] 编译通过（0 警告 0 错误），并输出标准发布包 `publish/UMM-v2.2.0-win-x64.zip`
