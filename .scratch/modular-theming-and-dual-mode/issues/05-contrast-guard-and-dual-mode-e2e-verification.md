# 05: 自动化对比度测试守卫与双态粉色主题包实装

Type: task
Status: resolved
Blocked by: 01, 03, 04

## 问题

为了保证未来任何新增主题、界面页面或组件扩展时，绝不再发生对比度劣化或孤岛系统蓝残留，必须在测试套件中建立起不可逆转的对比度守卫门禁；同时需要重新构建并实装一份真正的、同时具备白天与夜晚高保真设计的“樱花粉调 v2”标准主题包供用户端到端体验。

如何建立全自动化的 WCAG 2.1 AA 对比度测试守卫，并实装高品质双态主题包进行全流程验证？

## 验收条件

- [x] 在 `ModelBehaviorTests.cs` / `ThemeContrastGuardTests.cs` 中扩展对比度守卫矩阵：覆盖所有内置方案与自定义主题在白天与夜间两种状态下的前景色/背景色对比度断言（正文 ≥ 4.5:1，大元素 ≥ 3:1）
- [x] 自动化测试守卫断言：在任何主题应用后，WPF-UI 内部强调色与 `Application.Current.Resources` 必须与主题主色完全一致，禁止出现系统蓝 #0078D4 偏差
- [x] 重新生成并实装标准的日夜双态“樱花粉调 v2”（`SakuraPink.ummtheme`），内含独立的白天与夜间高分辨率壁纸及双套精致配色
- [x] 将更新后的产物扁平编译至 `bin\Debug\` 与 `publish\` 目录，全套测试绿灯通过（0 失败 0 警告）
- [x] 手动体验验证：双击导入能够预览日夜两套视觉，导入后点击左下角日夜按钮能在粉色白天与粉色夜晚间平滑热切换

## 答案

1. 建立 `ColorContrastHelper.cs`，实现标准 WCAG 2.1 相对亮度（非线性伽马校正）与对比度公式；
2. 建立 `ThemeContrastGuardTests.cs`，实现不可逆转的双态对比度自动化守卫矩阵：遍历所有内置调色板及常见自定义主题在 Dark/Light 下的对比度指标（正文 ≥ 4.5:1，次级文本 ≥ 3.0:1），并断言系统强调色绝不回退至系统蓝 #0078D4；
3. 实装官方标准的日夜双态“樱花粉调 v2”（`SakuraPink.ummtheme`），包含纯矢量渲染的 1920x1080 独立白天与夜间壁纸、双套高对比度设计代币与 Manifest v2；
4. 完成全套 131 项单元测试回归（0 失败 0 警告），并编译发布至 `publish/UMM-v2.2.0-win-x64/` 与 `publish/UMM-v2.2.0-win-x64.zip`。
