# 规格书：玩家自定义壁纸与高斯模糊个性化系统 (Custom Wallpaper & Frosted Blur Personalization)

Type: spec
Status: ready-for-agent

## 问题陈述

在现有的启动器设计中，壁纸资产曾被误绑定在主题包中，导致导入主题时全局所有视窗与二级页面（如设置页、模组列表页）被全屏大图壁纸侵占覆盖，破坏了 Fluent 设计语言的清爽质感，甚至影响了文字清晰度。同时，启动器此前未向玩家开放自主配置背景壁纸的通道，玩家无法在保持界面清晰整洁的前提下，自由定制符合个人偏好的背景与沉浸式毛玻璃视觉效果。

## 解决方案

实现**主题包色彩系统**与**玩家壁纸个性化系统**的正交解耦：
1. **主题包专精色彩与代币**：启动器所有窗口与页面永久以高质感纯色（`ApplicationBackgroundBrush`）为底座，主题包仅驱动色彩调色板与卡片质感；
2. **壁纸归属玩家自主配置**：在“设置”页中新增专属的“启动器背景壁纸与个性化”控制面板，允许玩家自主选择本地任意图片作为壁纸，或一键清除恢复纯色；
3. **分层毛玻璃宿主架构**：在主窗口建立单一壁纸宿主层，集成 GPU 硬件加速的 `BlurEffect` 高斯模糊渲染与自适应半透明遮罩层，保证无论玩家选择何种复杂的壁纸，上面的卡片与文字均能 100% 满足 WCAG 2.1 AA（$\ge 4.5:1$）无障碍可读性；
4. **实时交互滑块调节**：为玩家提供“模糊半径（0 ~ 40 px）”与“遮罩浓度（10% ~ 80%）”实时调节滑块，即拖即见效。

## 用户故事

1. 作为一个玩家，我想要在设置页面自主选择一张本地图片（PNG/JPG/WEBP）作为启动器背景壁纸，以便让启动器更具专属感与个性化。
2. 作为一个玩家，我想要自由调节背景壁纸的高斯模糊程度（Blur Radius），以便将过于复杂的插画柔化为极具现代感和高级感的毛玻璃背景。
3. 作为一个玩家，我想要自由调节背景壁纸的遮罩浓度（Dim Opacity），以便在保留壁纸色彩氛围的同时，确保界面卡片上的文字清晰可读、不晃眼。
4. 作为一个玩家，我想要在调整模糊度与遮罩滑块时实时看到启动器背景的变化，以便精确调节到我最舒适的视觉效果。
5. 作为一个玩家，我想要能够随时点击“清除壁纸”，以便一键回归最纯净、无任何图片干扰的原生 Fluent 纯色界面。
6. 作为一个玩家，我想要在切换不同页面（如从首页切到设置页、模组列表页）时壁纸平稳固定在窗口底层，以便消除多层重复绘制带来的卡顿或画面跳动。
7. 作为一个玩家，我想要在切换深色模式与浅色模式时，遮罩层能够自动适配当前模式的明暗基调，以便白天不刺眼、夜间不昏暗。
8. 作为一个玩家，我想要启动器能够自动持久化保存我的壁纸路径、模糊度与遮罩数值，以便下次冷启动时无缝恢复我的个性化设置。
9. 作为一个玩家，当我选择的壁纸文件被意外移动或删除时，我想要启动器能够安全平滑地回退至纯色背景，以便绝不发生崩溃或白屏错误。
10. 作为一名注重无障碍体验的用户，我想要开启任意壁纸与模糊效果后，主界面的重要按钮、状态徽章与正文仍然符合 WCAG AA 4.5:1 对比度标准，以便视读毫无障碍。

## 实现决策

### 1. 架构解耦与单层宿主管道 (Single Host Layer Pipeline)
- **底层纯色兜底**：主窗口与页面继续使用主题系统的纯色设计代币 `ApplicationBackgroundBrush`，壁纸绝不直接修改或劫持该代币；
- **单点渲染承载**：在主视窗根节点建立统一的视觉底座三层结构：
  1. `Layer 0 (Base)`：纯色背景，作为未启用壁纸时的默认底座及壁纸加载前的兜底；
  2. `Layer 1 (Wallpaper Host)`：单层 `Image` 控件，采用 `Stretch="UniformToFill"` 铺满视窗，并附加带有性能偏置选项的 GPU 硬件加速高斯模糊特效；
  3. `Layer 2 (Dim Overlay)`：半透明遮罩层，绑定当前主题的 `ApplicationBackgroundBrush`，通过动态调整透明度平衡壁纸氛围与文字对比度；
  4. `Layer 3 (UI Content)`：原有的标题栏、导航栏与主视窗页面内容，页面容器背景透明化，浮于遮罩层之上；
- **页面透明化规范**：各二级页面（如设置页、插件列表页）根背景由强制纯色改为透明穿透，统一透出主窗口的单一壁纸宿主层，彻底根除层叠 Overdraw。

### 2. 持久化数据模型扩充 (AppSettings)
- 在启动器全局配置模型中增加以下持久化字段：
  - `LauncherCustomWallpaperPath` (`string?`，默认 `null`，记录本地壁纸绝对路径)；
  - `LauncherWallpaperBlurRadius` (`double`，默认 `15.0`，有效范围 `0.0 ~ 40.0 px`)；
  - `LauncherWallpaperDimOpacity` (`double`，默认 `0.35`，有效范围 `0.10 ~ 0.80`)；
- 当壁纸文件路径为空或指向不存在的路径时，自动判定为未启用壁纸，宿主层平滑折叠，展现原生纯色。

### 3. 设置页面（SettingsPage）交互体系
- 在“主题模式与外观”区域下方新增“启动器壁纸与个性化”卡片组：
  - **当前壁纸指示器**：展示文件名及“已启用 / 未启用纯色”状态；
  - **操作按钮组**：提供“选择自定义壁纸”按钮（弹出系统文件选择对话框，过滤常见图片格式）与“清除壁纸”按钮；
  - **背景模糊度控制**：滑块控件（Slider），刻度范围 `0` 至 `40 px`，附带文本标签实时显示当前数值（如 `15 px (柔和)`）；
  - **遮罩浓度控制**：滑块控件（Slider），刻度范围 `10%` 至 `80%`，附带文本标签实时显示百分比（如 `35%`）。

### 4. 内存与 IO 安全
- 壁纸加载采用 `MemoryStream` 内存拷贝解耦，读取完成后立即释放系统文件锁，绝不占用玩家本地图片文件句柄；
- 加载过程包裹健壮的异常捕获与校验逻辑，遇到损坏文件或超大异常图片时安全回退。

## 测试决策

### 测试原则
- 坚守“只测试外部可观察行为，不测试私有实现细节”原则；
- 保持所有涉及 WPF 全局状态与资源更新的测试串行受控运行。

### 测试接缝规划 (Testing Seams)
1. **最高业务接缝（配置与模型接缝）**：
   - 测试 `AppSettings` 对壁纸路径、模糊度数值与遮罩浓度的持久化序列化、边界值 Clamp 与缺省回退行为。
2. **控制器与服务驱动接缝（Theme & Personalization Seam）**：
   - 模拟设置壁纸路径后，验证宿主状态属性更新、图片流安全加载、非阻塞文件锁定行为；
   - 验证清除壁纸后状态优雅重置为未启用状态。
3. **视觉对比度与稳定性回归接缝（WCAG AA Guard Seam）**：
   - 验证在应用最大与最小遮罩浓度、极端亮色/暗色壁纸场景下，卡片内文本与按钮的对比度依然守住 WCAG AA 4.5:1 红线；
   - 确保全软件全量测试套件（131+ 项测试）零破坏回归。

## 范围外

1. 动态壁纸与视频壁纸播放（如 MP4 / WebM / GIF 解码，属于后续性能专项）；
2. 多张壁纸定时轮播图库（本期专注于单张自定义壁纸与高精模糊调优）；
3. 在线社区壁纸市场或壁纸云同步（当前专注于本地单机自治物理管理）。

## 补充说明

- 本功能实装后，主题包规范（`.ummtheme v2`）将彻底专精于色彩体系与设计代币，壁纸的掌控权完全交给玩家自身；
- 该毛玻璃与遮罩设计符合 Windows 11 Fluent 与 macOS 现代半透明质感标准，兼顾审美自由与工具实用性。
