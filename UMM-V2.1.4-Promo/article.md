# UMM v2.1.4 宣传资料

## 一句话定位

Unturned Mod Manager（UMM）是面向 Windows 的 Unturned 启动、BepInEx 插件管理与 unmod.online 社区客户端。v2.1.4 延续 .NET 8 + WPF 路线，把社区发现、插件安装、本地控制、任务追踪和安全更新放在同一个可理解、可撤销的工作流里。

## 从 v2.0 开始的正式产品

UMM v2.0 是一次正式发布：它把主窗口、游戏启动、本地插件、社区、详情、设置和账户界面统一起来，建立了 ViewModel/Service 分层、导航历史、账户会话、缓存和可恢复安装行为。此前的版本验证了启动和环境部署；v2.0 则首次以完整启动器的形态交付给玩家。v2.1.4 在这条稳定基础上继续补齐图片预览、任务中心、账户身份、主题一致性和手动更新体验。

## 它解决什么问题

插件环境通常涉及游戏目录、BepInEx、DLL 文件、依赖、版本和启动模式。手动复制文件很难知道当前状态，也不容易恢复。UMM 的目标不是替代 Steam 创意工坊，而是补上客户端逻辑插件和本地环境管理这一层：让玩家看得见环境状态，知道插件来自哪里，并能在出错时找到原因。

## 一次日常使用

第一次使用时，UMM 可以探测 Steam Library 中的 Unturned，也允许手动选择游戏目录。完成环境准备后，玩家可以在首页检查 BepInEx、全局插件开关和 DXVK 状态，选择模组模式启动游戏，或切换到原版模式运行 `Unturned_BE.exe`。进入本地插件页可以批量启停和卸载插件；进入社区页可以搜索、查看详情、安装依赖和更新版本。所有操作都在启动器内留下状态、通知或任务记录，玩家不必再反复打开游戏目录确认文件是否生效。

## v2.1.4 的核心能力

### 发现与安装

- 连接 unmod.online 社区，浏览分类、排序和搜索结果；筛选条件变化后自动刷新，并可读取最近缓存。
- 社区首页只展示条目摘要，点击条目后进入独立详情页。详情展示作者、版本、分类、文件大小、下载量、点赞量、依赖数量和当前安装状态。
- 插件封面可打开原尺寸预览，支持滚动、缩放、Ctrl + 滚轮和 Esc 关闭。详情 Markdown 中的 HTTPS 图片也会进入同一套安全预览流程，不执行远程 HTML 或脚本。
- 安装前解析依赖并显示安装意图；安装、更新和卸载都经过文件所有权、路径穿越、大小和哈希检查。

### 本地控制

- 递归扫描 `BepInEx/plugins` 中的 `.dll` 和 `.dll.disabled`，区分社区托管插件与玩家手动安装插件。
- 本地插件支持启用、停用、导入、卸载；匹配到社区条目时可以跳转到对应详情并更新版本。
- 每个 Unturned 安装目录都可以保存多个插件方案。方案只记录 DLL 的启停快照，例如“联机优化”或“开发调试”；应用时不会复制插件、删除文件、改写配置，也不会挂载 WinFsp 虚拟盘。应用方案前会验证全部目标文件；任何移动失败都会按相反顺序回滚。

### 环境与诊断

- 支持安装、升级、修复、临时停用和卸载 BepInEx 5.4.23.5（win_x64、Unity Mono、winhttp doorstop）。卸载环境会移除核心和 Doorstop 文件，但保留玩家插件、配置、缓存、日志和社区安装记录。
- 使用 `winhttp.dll` / `winhttp.dll.disabled` 切换模组模式和原版模式；模组模式使用 `Unturned.exe -NoBattlEye`。
- 可选部署 DXVK 2.4，并优先使用可识别的非虚拟适配器给出兼容性提示；远程桌面和常见虚拟显示驱动会被跳过。首页可以分析 Unity、Unturned、BepInEx 和 DXVK 日志，并导出不上传的诊断包。

### 任务与恢复

任务中心统一记录插件安装、更新和卸载：流式下载百分比、已接收/总大小、当前阶段、失败原因、尝试次数和操作历史都会显示出来。失败任务可以在同一次启动中重试；更新失败时安装器恢复旧文件，卸载前会校验文件哈希，发现文件被用户修改就停止删除。

### 账户、主题与更新

- 浏览器登录并在网页中完成人机验证，UMM 通过本机 `localhost` 回调接收社区令牌；侧栏可显示头像、服务端返回的身份和用户名。超长文本自动省略，悬停可以查看完整内容。
- 侧栏展开状态、窗口尺寸与位置、账户会话和主题偏好都会保存。主题支持浅色、深色和跟随系统，并提供六套配色；按钮、开关、进度条、导航选中和焦点状态会同步使用当前强调色。
- 首页欢迎区和版本公告可以关闭。UMM 只查询官方 GitHub Release；检测到更高版本时提供手动下载并安装，下载文件必须通过来源、大小和 SHA-256 校验，替换前保留 `.bak`，不静默更新。

## 技术与边界

UMM v2.1.4 使用 .NET 8、WPF、WPF-UI 3.0.5，采用 Pages + ViewModels + Services 分层。它借鉴了 Ayndpa 的 `unturned-mod-loader` 在社区浏览、列表—详情、登录回调和导航历史上的实践，但保持独立实现；UMM 不使用 UML 的 WinFsp 虚拟盘，也不占用 `unmod://` 协议。项目按 GPL-2.0-only 发布，第三方项目继续遵守各自许可证。
