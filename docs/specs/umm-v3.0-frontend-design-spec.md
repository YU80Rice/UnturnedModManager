## 1. 设计目标与定稿架构决策（B+C 混合方案）

UMM v3.0 前端设计从旧版固定左栏升级为 **Fluent 2 / PCL2 风格「顶部胶囊导航 + 底部停靠指挥舱」**（交互稿默认 `data-layout="BC"`）：

| 维度 | v2.2.1 现行实现 | v3.0 定稿设计 |
| :--- | :--- | :--- |
| **主框架导航** | `NavigationView` 左侧可折叠边栏 | 取消左侧展开栏；采用 **顶部居中 5 槽位分段胶囊导航**（开始游戏 / 模组工坊 / 任务中心 / 游戏设置 / 关于） |
| **启动控制中心** | 首页内嵌启动区 | **底部停靠式全局指挥舱（70px Docked Footer）**：左侧显示方案/模组数/运行模式/BepInEx 与 DXVK 状态，右侧放置放大图标与体量的单一 `开始游戏` CTA 按钮 |
| **模式切换方式** | 独立多处模式入口 / 下拉菜单 | **取消底部指挥舱旁的模式切换下拉菜单**，仅保留 **首页「全局模组环境」开关**，直接联动底部指挥舱显示 `模组模式 · -NoBattlEye` 或 `纯净模式 · Unturned_BE.exe` |
| **配色系统** | 7 套固定 `ThemePalette` 枚举方案 | **取消 7 套预设方案**，改为 **默认仅圆环+环上滑块、点击后展开完整滑块的 HSV 调色环**，实时派生双模颜色与 WCAG 对比度 |
| **模组页面组织** | `ModListPage` 与 `CommunityPage` 分列导航 | 合并为统一 **模组工坊（PluginWorkshop）** 顶栏双标签（`本地插件` / `社区发现`），社区列表采用 3 列响应式卡片网格，点击详情保留单根来源返回 |
| **深浅弹窗一致性** | `AccountWindow` 存在深色黑字，`Import`/`Sandbox` 存在硬编码浅色画刷 | 全部 6 类弹窗（账户 / 首次向导 / `.ummpk` 审查 / `.ummtheme` 审查 / 安全沙箱拦截 / 大图缩放）严格绑定主题动态画刷与对比度保护 |

## 2. 主视窗与外壳空间规范（`MainWindow`）

1. **三层壁纸渲染架构（必须无损保留）**：
   - **Layer 0（纯色底座）**：绑定动态派生 `ApplicationBackgroundBrush`（`--app-bg`），作为任意透明穿透或未设壁纸时的稳定兜底。
   - **Layer 1（壁纸宿主层）**：单层 `Image` + GPU `BlurEffect`（模糊半径 `0px ~ 40px`，默认 `15px`）。
   - **Layer 2（对比度遮罩层）**：绑定 `--app-bg` 半透明覆盖（浓度 `10% ~ 80%`，默认 `35%`），保证卡片与正文始终清晰可读。
   - **Layer 3（透明外壳与页面层）**：顶栏胶囊、主工作区视口与底部指挥舱承载在半透明磨砂层之上，禁用多层重叠高开销模糊。
2. **顶部胶囊导航栏**：
   - **左区**：游戏识别与 Steam 状态胶囊（`Unturned · Steam 304930`，点击跳转本地插件）。
   - **中区（分段胶囊组）**：`开始游戏`、`模组工坊`、`任务中心`（含运行中/失败徽标）、`游戏设置`、`关于`。
   - **右区**：`浅色 / 深色` 快速切换图标按钮 + 社区账户状态胶囊（头像首字母/头像 + 用户名）。
3. **底部全局启动指挥舱（`.docked-command-bar`）**：
   - 高度 `70px`、左右内边距 `24px`，紧贴主工作区底部（不遮挡或悬浮覆盖卡片内容）。
   - **左侧状态区**：
     - 方案状态胶囊：`方案：<当前方案名> · <已启用>/<总数> 插件`；当主页 `全局模组环境` 关闭时实时显示 `方案：<当前方案名> · 0 插件 (纯净)`。
     - 运行模式胶囊：`模组模式 · -NoBattlEye` 或 `纯净模式 · Unturned_BE.exe`（完全随首页 `全局模组环境` 开关同步，不在此处设置展开菜单）。
     - 底层环境胶囊：`BepInEx 5.4.23.5 就绪 · 原生 D3D11 / DXVK 2.4`。
   - **右侧单一主按钮（`.cmd-launch-cta`）**：
     - 高度 `46px`、水平内边距 `28px`、圆角 `10px`、字号 `15px`、`font-weight: 700`、按钮与图标间距 `9px`。
     - 播放图标尺寸放大至 `21×21`（原常规图标为 `15×15`）。
     - 按钮旁 **不保留** 模式切换展开菜单。
4. **交互保留契约**：保留 `ScrollWheelRouter`（`PreviewMouseWheel` 隧道转发，防止卡片/输入框吞掉滚轮）与主窗体文件拖拽导入 `.ummpk` / `.ummtheme`。

## 3. 点击展开式 HSV 调色环与动态色彩派生引擎

### 3.1 两段式交互形态（所有调色入口统一规范）

- **默认收起态（仅圆环 + 环上滑块）**：
  - 设置页 / 首次向导使用 `124×124` 纯色相圆环（顶栏测试浮层使用 `140×140`），仅显示 360° 连续色相环、环上可拖拽圆形滑块（Puck）以及环中心 `58×58` 可点击主题色圆钮。
  - 默认态 **不显示** 内部二维 SV 方块、**不展开** 四条滑动条与语义色块预览，避免占用设置页纵向首屏空间。
  - 若当前处于低饱和/极暗灰阶状态时直接拖拽收起态圆环，自动恢复为可用高可视彩度（如 `S >= 78%`、`V >= 84%`），确保拖拽圆环必然立刻产生直观色相变化。
- **点击完全展开态（完整滑块微调）**：
  - 点击 **圆环中心色钮** 或 **`展开完整滑块` 按钮** 后就地展开：
    - 完整二维配色器：外圈 360° 色相环 + 内嵌正方形 **饱和度 `S` × 明度 `V` 调色盘**（设置页 `216×216`、弹窗与向导 `176×176`）。
    - **HEX 输入框**（支持实时输入 `#RRGGBB` 并同步轮盘位置）。
    - **文本对比度实时检验标签**（`4.5:1 (AA)` / `7.0:1 (AAA)`）。
    - **四条完整滑块**：`色相 H (0°~359°)`、`饱和度 S (0%~100%)`、`明度 V (0%~100%)`、`氛围染色 (0%~40%，默认 16%)`。
    - **5 项实时语义配色条**（强调主色 / 悬浮高亮 / 文字高亮 / 窗口底色 / 卡片表面）与 **`收起滑块`** 按钮。
- **恢复默认**：提供单一 `恢复默认 (#0078D4)` 复位按钮（默认氛围染色 `16%`）。

### 3.2 动态颜色派生规则与 WCAG 对比度守卫

给定用户选择的主色 `(H, S, V)` / `accentHex`、当前主题模式 `mode`（`dark` / `light`）以及 `surfaceTint ∈ [0, 40]`：

1. **中性底色与氛围染色（Surface Tint）**：
   - 计算有效染色系数：$t = (\text{surfaceTint} / 100) \times (S / 100)$。当 $S = 0$（纯黑白灰）时 $t = 0$，界面底色保持纯粹中性灰。
   - **深色基线**（线性 RGB 混合至同色相低明度暗调 `hslToHex(H, 40~54%, 15~42%)`）：
     - `--app-bg`: `#1B1C20` 混入 `t * 0.72`
     - `--card-bg`: `#24262C` 混入 `t * 0.65`
     - `--card-bg-2`: `#2D3038` 混入 `t * 0.68`
     - `--card-bg-3`: `#373B44` 混入 `t * 0.70`
     - `--border-color`: `#444854` 混入 `t * 0.75`
     - 文字基线 `--text-primary`（`#F5F6FA` 轻混 `t * 0.25`）、`--text-secondary`（`#C6CAD4` 轻混 `t * 0.30`）、`--text-tertiary`（`#969BA8` 轻混 `t * 0.28`）。
   - **浅色基线**（混入同色相柔和亮调 `hslToHex(H, 40~58%, 74~98%)`）：
     - `--app-bg`: `#F2F4F7` 混入 `t * 0.95`
     - `--card-bg`: `#FFFFFF` 混入 `t * 0.45`
     - `--card-bg-2`: `#EFF1F5` 混入 `t * 0.85`
     - `--card-bg-3`: `#E3E6EC` 混入 `t * 0.85`
     - `--border-color`: `#CFD5DF` 混入 `t * 0.80`
     - 文字基线 `--text-primary`（`#1A1D24`）、`--text-secondary`（`#565B68`）、`--text-tertiary`（`#646B7A`）。
2. **主色衍生与可读性兜底**：
   - `--on-accent`：比较 `accentHex` 与 `#FFFFFF` 及 `#111111` 的相对亮度对比度，择优选择前景色。
   - `--accent-hover`：若 `relLuminance(accentHex) > 0.35`，则向 `#000000` 混合 `12%`；否则向 `#FFFFFF` 混合 `14%`，确保极黑/极白主色下悬浮态依然可辨。
   - `--accent-text`（卡片/正文中的高亮文字）：当 $S < 8$ 时使用 `#D8DCE6`（深色）/ `#242934`（浅色）；否则在 $H$ 下分别向深色亮区（$L \in [70, 92]$）或浅色暗区（$L \in [18, 42]$）步进搜索首个与 `--card-bg` 对比度 $\ge 4.8:1$ 的颜色。
   - **边框防隐身守卫**：当 `contrastRatio(accentHex, cardBg) < 1.38` 时，主按钮外描边 `--accent-btn-border` 自动切换为半透明白（深色）或半透明深墨（浅色）；当纯黑或纯白选色导致柔光背景不可见时，`--accent-soft` / `--accent-border` 改用 `--accent-text` 作为透明度基底。
3. **v2.x 历史配置与 `.ummtheme` 兼容建议**：
   - 读取旧版 `AppSettings.CommunityColorPalette`（`Fluent` / `WarmPaper` / `MascotOrange` / `MistyForest` / `OceanDusk` / `KleinBlue` / `Lavender`）时，可在首次迁移至 v3.0 时映射为其对应的初始 `AccentHex`，不再暴露 7 套独立配色切换器。
   - 导入 `.ummtheme` 时同步解析其 `accent_color` 并写入调色环状态（仍遵循 `docs/specs/ummtheme-specification-v2.md` 安全沙箱校验）。

## 4. 页面与弹窗设计清单

### 4.1 五大主页面

1. **开始游戏（`HomePage` · 2×2 Bento 网格）**：
   - **左上卡（运行概要与当前方案）**：显示 `当前方案`、`启用模组 (X/Y 插件)`、`当前模式 (模组 -NoBattlEye / 原版 BattlEye)` 及 `GAME ROOT` 路径。
   - **右上卡（UMM 欢迎区 · v3.0）**：显示版本亮点、更新日志弹窗入口与“收起欢迎区”按钮，右侧嵌入 `umm-mascot-chibi-v2.png` Q 版吉祥物光晕卡片；支持在设置中关闭。
   - **左下卡（BepInEx 与图形环境）**：展示 `BepInEx 5.4.23.5` 校验状态与修复/卸载/安装操作，包含 **「全局模组环境」主开关** 与 **「DXVK 2.4 渲染」开关**，并附带显卡（GPU）型号识别与 DXVK 推荐测试提示。
   - **右下卡（崩溃诊断与日志分析）**：提供只读 `分析最近日志` 与 `导出脱敏诊断包`；触发异常线索时展示结构化报错（`MissingDependency` / `BattlEyeConflict` 等）与一键修复建议。
2. **模组工坊（`PluginWorkshopPage`）**：
   - 顶部工具条切换 **本地插件** / **社区发现**；本地插件支持方案增删改查切换（物理重命名 `.dll` / `.dll.disabled`）、`.ummpk` 导入导出与逐项启停/更新/卸载；社区发现支持搜索、分类/排序筛选、`unmod.online` 状态指示与 3 列卡片展示。
   - 点击插件卡片进入 **社区详情页（`CommunityDetailPage`）**，保留顶部明确返回源按钮与前置依赖一键跳转、封面点击放大预览。
3. **任务中心（`TaskCenterPage`）**：展示进行中进度条、已完成记录与失败项错误原因（含一键重试、清理已完成记录与跳转到对应插件详情）。
4. **游戏设置（`SettingsPage`）**：
   - Card 1：Unturned 游戏根目录浏览与 Steam 自动寻找；
   - Card 2：首页欢迎公告开关 & 社区账户管理；
   - Card 3：深浅模式切换 + **默认收起式 HSV 调色环** + `.ummtheme` 导入/导出/`恢复默认 (#0078D4)`；
   - Card 4：三层壁纸预设、自定义图片选择、背景模糊半径（`0~40px`）与遮罩浓度（`10%~80%`）双滑块；
   - Card 5 & 6：Windows 文件关联（`.ummpk` / `.ummtheme` / `umm://`）修复与解除、重跑首次向导、保存设置。
5. **关于（`AboutPage`）**：版本徽标、GPL-2.0-only 许可声明、贡献者 Bento 卡片与设计致谢说明。

### 4.2 六类弹窗（全部支持深/浅双模高对比度）

- `AccountWindow`：社区登录 / 个人资料卡（彻底修复深色模式黑字不可读问题，强制绑定 `--text-primary`）。
- `OnboardingWindow`：3 步首次设置向导（1 目录选择 → 2 明暗模式 + 可展开式 HSV 调色环 → 3 完成确认）。
- `ModPackageImportWindow`：`.ummpk` 解包前清单预览、目标方案选择与 `.cfg` 保留 / `.dll.bak` 自动备份策略。
- `ThemePackageImportWindow`：`.ummtheme` 夜间/日间双模配色与壁纸效果预览确认。
- `SandboxAlertWindow`：安全沙箱违规拦截高对比度警示（无任何跳过/绕过按钮，附带排障诊断信息复制）。
- `ImagePreviewWindow`：暗色画布封面图滚轮缩放（`50% ~ 250%`）与百分比复位工具栏。

## 5. 后续专场构建与 WPF 升级路线建议

待开启 WPF v3.0 专属升级分支时，可按以下顺序推进并验收：
1. **主题核心升级**：改造 `ThemeService.cs` 与 `AppSettings.cs`，新增原生 `Controls/ColorWheelControl`（实现“默认仅圆环、点击展开完整滑块”）。
2. **主窗体 B+C 外壳落地**：更新 `MainWindow.xaml/.cs`，保留三层壁纸层与 `ScrollWheelRouter`，切换为顶栏分段胶囊 + 底部 `70px` 启动指挥舱与放大版 `开始游戏` CTA。
3. **五页面与六弹窗迁移**：更新 `HomePage`、`PluginWorkshopPage`、`SettingsPage`、`OnboardingWindow` 及全部二级页面/弹窗的画刷绑定与交互适配。
4. **回归与发布验证**：
   - 保持现有业务适配器、物理 `.dll/.dll.disabled` 管理、安全沙箱白名单与 `UnturnedModManager.exe` 主文件名规范不变。
   - 更新并运行 `UnturnedModManager.Tests`（确保全量测试通过），并在 Release 编译后补充真机离屏渲染截图核验极限色相（纯红/亮黄/深紫/黑白）在深浅双模及壁纸叠加下的可读性。
