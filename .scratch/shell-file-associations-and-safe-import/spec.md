# Spec: Windows 原生文件关联与安全导入审查向导

## 问题陈述
玩家之间在社区或社交群组中频繁分享 `.ummpk` 模组包和 `.ummtheme` 主题包。在当前版本中，双击这些文件无法直接由 UMM 启动器打开，必须手动启动程序并寻找文件导入入口。同时，若引入外部文件的自动打开，若直接在后台静默解压，极易导致玩家已有的配置文件（`.cfg`）被无意抹除覆盖，或者被夹带恶意脚本的可疑压缩包侵害。

## 解决方案
在 Windows 平台为 UMM 注册 `.ummpk` 和 `.ummtheme` 的原生打开方式与文件类型图标，并提供设置页手动管理。当用户双击相关文件时，单实例服务将参数路由至主进程置顶唤醒；启动器在执行沙箱白名单与解压预检后，弹出专用的“导入审查向导”，清晰列出包内包含的插件/主题元数据与文件变更，由用户明确确认后方才物理写入。若发现违规文件（如可执行载荷），立即阻断并展示红色安全告警。

## 用户故事
1. 作为玩家，我想要双击任意 `.ummpk` 模组包，以便快速唤醒 UMM 启动器并查看其中包含的模组与配置清单。
2. 作为玩家，我想要在导入审查向导中看到冲突提示（如已存在的同名插件或配置文件），以便决定是否保留我当前的本地个性化设置。
3. 作为玩家，我想要在导入模组包时选择将其合并至当前活跃 Profile，或者以此包快速新建一个独立的 Profile 隔离存放。
4. 作为玩家，我想要在覆盖同名插件时自动生成 `.bak` 备份，以便在模组出现异常时随时回滚。
5. 作为玩家，我想要双击 `.ummtheme` 主题包，以便快速预览主题配色与壁纸，并选择是否立即应用。
6. 作为玩家，我想要在面对包含恶意脚本（如 `.bat` / `.exe`）的篡改包时收到醒目的红牌警示与拦截原因，以便保护电脑系统安全。
7. 作为便携式（绿色版）用户，我想要在设置页手动解除或修复文件关联，以便随时保持系统注册表干净整洁。
8. 作为玩家，我想要在短时间内连续双击多个包文件时，启动器能够依序排队处理，以便避免多个弹窗重叠或冲突。

## 实现决策
- **注册表打开方式管理**：
  - 在非隔离运行模式下，自动维护 `HKCU\Software\Classes\.ummpk` 与 `.ummtheme`，关联到当前进程可执行文件路径；
  - 在设置页提供“修复关联”与“解除关联”显式按钮；
  - 检测到便携隔离环境变量（`UMM_DATA_DIRECTORY` / `AppDataPaths.IsIsolatedProfile`）时绝对静默，禁止写入注册表。
- **命令行与单实例派发**：
  - 扩展命令行参数解析，识别传入的 `.ummpk` 和 `.ummtheme` 本地文件路径；
  - `SingleInstanceService` 接收到次级激活参数时，将文件路径送入 FIFO 队列；
  - 主窗口使用单一模态守护（Single Modal Guard），若当前正在显示向导或处于首启动流程中，暂存队列，待空闲时依序弹出下一个导入包。
- **安全审查向导与预检流水线**：
  - 导入前执行严格沙箱检查：解压条目 <= 4096，解压总体积 <= 1GB，禁止路径穿越，严格白名单目录（`BepInEx/plugins/**` 与 `BepInEx/config/**`），拦截任何可执行/脚本扩展名；
  - 触发沙箱规则时，弹出红色警示弹窗（Strict Red Alert），禁止继续导入并展示违规文件列表；
  - 通过预检后，展示导入审查向导：提供 Profile 目标切换/新建下拉框、冲突标识、同名插件备份（`.bak`）、`.cfg` 保留本地配置选项（默认勾选）。
- **主题包导入与即时生效**：
  - `.ummtheme` 导入向导展示主题元数据与背景资产预览；
  - 提供“立即应用该主题”复选框（默认选中），确认后解压至本地主题目录并触发热切换与持久化。

## 测试决策
- **只测试外部行为，不测试实现细节**：
  - 测试命令行参数与文件路径意图解析：正确识别 `.ummpk`、`.ummtheme`、`umm://` 协议及忽略未知参数；
  - 测试沙箱预检规则：验证路径穿越、危险扩展名拦截、条目数限制的精确拒绝行为；
  - 测试模组包冲突识别与配置保留逻辑：验证同名文件检测、`.bak` 命名与覆盖标记；
  - 测试注册表键生成器逻辑（纯函数/跨平台防呆）：确保便携模式与非 Windows 平台的安全跳过。
- **测试先例**：
  - 遵循 `UnturnedModManager.Tests/ModelBehaviorTests.cs` 的轻量、无 UI 阻塞、内存中快速验证模式。

## 范围外
- 不捆绑或检测任何外部联机网络桥（如 `LaunchMultiplayerNet`）。
- 不引入系统驱动级或虚拟文件系统（VFS）扩展。
- 不提供静默自动无感知安装模式。
