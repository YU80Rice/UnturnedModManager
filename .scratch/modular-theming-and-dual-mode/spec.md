# Spec: 深度模块化主题系统 2.0 与日夜双态生态

## 问题陈述
玩家与模组作者在应用主题包（`.ummtheme`）或预设调色板时，发现界面的色彩模块化不够彻底：
1. 主页欢迎区徽章、版本标签、更新要点小圆点、运行日志图标、关于页魔方 Logo 背景、版本药丸条、GitHub 超链接以及左侧栏用户头像等组件，依然固定显示为 WPF-UI 框架默认的系统蓝（#0078D4），未能与当前选择的主题色同步，形成视觉孤岛；
2. 现有主题包规范仅支持单一模式（通常为深色夜间模式），当玩家在白天或明亮环境下切换为浅色/白天模式时，主题包失效或缺少和谐的白天视觉，造成体验割裂；
3. 导入审查向导中存在部分文字标签未显式声明高对比前景，在特定深色容器中退化为 Windows 默认黑字，导致严重的对比度不足（黑字暗底），违反无障碍与可用性原则。

## 解决方案
构建 Unturned Mod Manager 深度模块化主题系统 2.0：
1. 建立全局语义化设计代币（Semantic Design Tokens）体系，彻底打通 WPF-UI 底层强调色管理总线（`ApplicationAccentColorManager`），将散落各处的组件样式统摄于主题总线之下，彻底根除硬编码与残留的默认系统蓝；
2. 推出 `.ummtheme v2` 规范，支持白天（Light）与夜间（Dark）双态调色板及双壁纸资产定义；同时提供针对旧版 v1 单模态主题的自动升级与浅色高对比度算法派生引擎，确保生态资产 100% 向下兼容；
3. 重构运行时日夜切换流水线，允许玩家在激活自定义主题时，点击底栏模式切换能够在当前主题的“白天版”与“夜间版”之间丝滑热切换，并在重启后完整持久化；
4. 全面修正所有弹窗与界面的文本样式，落实 WCAG 2.1 AA 级对比度基线，并在审查向导中提供生动的日夜双态交互预览能力。

## 用户故事
1. 作为玩家，我想要在导入并应用粉色或橙色主题后，主页欢迎区徽章、版本标签与更新小圆点均变为对应主题色，以便获得浑然一体的视觉体验。
2. 作为玩家，我想要在关于页面看到魔方 Logo 底色、版本号药丸、超链接与个人头像均同步当前主题色，以便彻底摆脱与主题格格不入的默认蓝色。
3. 作为玩家，我想要在白天光线明亮时切换到白天模式，自定义主题能够自动呈现出干净温润的浅色调（而非刺眼的暗色强行反转或回退系统默认），以便保护视力并保持个性化。
4. 作为主题作者，我想要在一个 `.ummtheme` 包内同时打包夜间与白天两张壁纸及双套配色，以便为玩家提供全天候的专属视觉设计。
5. 作为玩家，我想要在导入历史遗留的旧版 v1 主题包时，系统自动为其派生出高对比度的白天模式，以便我旧有的喜爱主题在新版本中依然完美可用。
6. 作为玩家，我想要在主题包审查向导中通过开关自由预览该主题在“白天”与“夜间”下的色卡与壁纸缩略图，以便在导入前做出充分审查。
7. 作为玩家，我想要在导入向导中清晰看清所有标题、说明与颜色编码，绝不出现黑字暗底或对比度不足，以便轻松阅读。
8. 作为玩家，我想要在切换日夜模式并重启启动器后，程序能够准确恢复我之前所选的主题及其对应的日/夜形态，以便免去重复设置的繁琐。

## 实现决策
- **WPF-UI 核心色彩总线挂接与代币化**：
  - 在全局调色板应用流水线中，显式调用底层强调色管理器的应用接口，同步更新内部主题字典与画刷资源；
  - 梳理主页、关于页与主框架视窗，将直接依赖外部隐式资源的组件统一重构为语义化动态笔刷（如 `AccentFillColorDefaultBrush`、`TextOnAccentFillColorPrimaryBrush`）；
  - 确保导航栏头像圆底、关于页魔方 Logo 底色、超链接前景与状态徽章 100% 绑定到语义代币。
- **.ummtheme v2 双态数据规范与兼容引擎**：
  - 扩展自定义主题数据结构，新增显式日间属性（浅色背景色、浅色卡片背景色、浅色壁纸文件名等）；
  - 升级安全沙箱条目校验规则，支持验证并解压提取日夜双壁纸资源；
  - 实现 v1 主题自动升权器：若检测到输入主题仅有暗色配置，算法自动基于主强调色计算出高对比度浅色调（明度与饱和度调和），生成完备的双模对象；
  - 导出主题包时，默认封装为符合 v2 规范的双模结构。
- **运行时日夜自适应与持久化**：
  - 改进底栏日夜切换入口与设置页逻辑：检测到活跃自定义主题时，切换操作执行该主题内部的白天态与夜间态热切换，更新当前背景壁纸与色彩代币，避免粗暴回退默认预设；
  - 在配置存储中记录当前主题在双模下的活跃状态，应用冷启动时精准恢复。
- **导入审查向导无障碍与交互重构**：
  - 为向导窗口的所有 TextBlock 明确指定高对比度前景代币，根除默认黑字在暗底上的对比度缺陷；
  - 增加“日间预览 / 夜间预览”联动切换器，点击后即时刷新调色板预览色卡、Hex 文本与壁纸视图。

## 测试决策
- **只测试外部行为，不测试实现细节**：
  - 测试主题应用后，资源总线与动态画刷是否精准匹配主题主色（断言不存在任何默认系统蓝残留）；
  - 测试旧版 v1 单模态主题的算法派生行为：验证生成的日间背景与卡片色是否具备合法 Hex 格式与预期的色彩倾向；
  - 测试双壁纸安全沙箱检验与解压提取：验证 `wallpaper_dark.png` 与 `wallpaper_light.png` 的合法放行与恶意路径拦截；
  - 测试日夜模式切换行为：验证在自定义主题激活状态下切换 Light/Dark，主题保持活跃且目标画刷按预期翻转；
  - 测试色彩对比度矩阵：计算所有配色在日夜模式下的前景与背景对比度，强制断言符合 WCAG 2.1 AA 基线（常规文本 ≥ 4.5:1，大元素 ≥ 3:1）。
- **测试先例**：
  - 延续 `ModelBehaviorTests.cs` 与 `ThemePackageImportTests.cs` 的轻量、快速、确定性测试惯例。
