# 05: 自动化对比度测试守卫与双态粉色主题包实装

Type: task
Status: ready-for-agent
Blocked by: 01, 03, 04

## 问题

为了保证未来任何新增主题、界面页面或组件扩展时，绝不再发生对比度劣化或孤岛系统蓝残留，必须在测试套件中建立起不可逆转的对比度守卫门禁；同时需要重新构建并实装一份真正的、同时具备白天与夜晚高保真设计的“樱花粉调 v2”标准主题包供用户端到端体验。

如何建立全自动化的 WCAG 2.1 AA 对比度测试守卫，并实装高品质双态主题包进行全流程验证？

## 验收条件

- [ ] 在 `ModelBehaviorTests.cs` 中扩展对比度守卫矩阵：覆盖所有内置方案与自定义主题在白天与夜间两种状态下的前景色/背景色对比度断言（正文 ≥ 4.5:1，大元素 ≥ 3:1）
- [ ] 自动化测试守卫断言：在任何主题应用后，WPF-UI 内部强调色与 `Application.Current.Resources` 必须与主题主色完全一致，禁止出现系统蓝 #0078D4 偏差
- [ ] 重新生成并实装标准的日夜双态“樱花粉调 v2”（`SakuraPink.ummtheme`），内含独立的白天与夜间高分辨率壁纸及双套精致配色
- [ ] 将更新后的产物扁平编译至 `bin\Debug\` 与 `publish\` 目录，全套测试绿灯通过（0 失败 0 警告）
- [ ] 手动体验验证：双击导入能够预览日夜两套视觉，导入后点击左下角日夜按钮能在粉色白天与粉色夜晚间平滑热切换
